HYVE サイト内オーディオプレーヤー＋太字フォント復元パッチ

差し替えファイル：index.html / css/style.css / js/main.js / admin/config.yml
データ保護のため data/site.json は含みません。

実装：YouTube iframeを削除し、HTML5 audioでローカルのMP3/M4A等をページ内で再生します。
代表曲リスト内の曲に音源ファイルが設定されていれば「▶ PLAY」を表示。未設定なら従来の外部LISTENリンク。
管理画面 → HYVE公式サイト → 代表曲 →「サイト内再生用の音源」から音源をアップロードしてください。
アップロード先：assets/audio（なければCMSが作成）。既存曲の音源データは提供されていないため本パッチに音源は入っていません。
必ず公開・試聴の権利がある音源のみ使用してください。試聴用の短いMP3がおすすめです。
GitHubのファイルサイズ制限（Web UI 25MB/file、git 100MB/file）に注意してください。長尺は音声容量を圧縮してください。

重要：以前から管理画面で編集した data/site.json は上書きしないでください。
CSSの最後でImpact書体を優先指定。見出しはHYVEだけ黄色、その他白。
テスト：音声登録後に公開サイトの▶ PLAYを押す／URLを直接開いて音声が再生できるかを確認。
